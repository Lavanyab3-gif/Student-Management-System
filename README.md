# Student Management System

A full-stack Student Management System developed using **Java, Spring Boot, React.js, and MySQL**. The application provides REST APIs for managing student information and uses React.js for the frontend.

## Features

- Add new student
- View all students
- Update student details
- Delete student
- REST API integration
- MySQL database integration
- React.js frontend
- Spring Boot backend
- CRUD operations

## Technologies Used

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API

### Database
- MySQL
